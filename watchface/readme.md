# LUMEN ORBIT 1.9.2 — 再ビルド

## 成果物の返却・引き継ぎルール

配布ファイル名は固定し、履歴はGitのコミットで管理します。
アプリ内部のバージョン番号は、端末の更新判定のため維持します。

このウォッチフェイスの成果物を返す際は、変更の有無にかかわらず、最終回答に
対応する最新版の次の3ファイルを、必ずこの順でまとめて提示してください。

1. `lumen-orbit-bip6.zpk`：最適化済みの端末向けパッケージ。
2. `lumen-orbit-bip6-rebuild-source.zip`：再ビルドに必要なソース・画像・設定・依存関係・手順。
3. `lumen-orbit-bip6-optimization.zip`：最適化に必要なスクリプト・依存関係・実行手順。

3ファイルは同じリリースに対応させてください。source ZIPと最適化用ZIPは分離し、
不要な照合結果・作業記録は含めません。別セッションでもこの3ファイルを使うため、
この返却ルールを両ZIPのREADMEに引き継いでください。

対象：Amazfit Bip 6。Node.js と npm、およびインターネット接続が必要です。
ビルドツールは package-lock.json で固定しています（Zeus CLI 1.9.3）。

## 改善方針

目標は、現在の表示・機能を維持し、実機で正しく軽く動くこと。
最適化の採否は、実行時の処理とメモリの無駄を減らせるかで決める。

- 容量だけ減らす変更は採用しない。ZIP圧縮率の追求は打ち切る。
- 不要な更新・重複処理・描画領域を削る。標準ウィジェットで済む処理を自作しない。
- 見た目・配置・回転中心・透明度を維持する。秒針などの機能を削らない。
  容量のために毎回の復号・描画処理を増やす変更は却下する。
- 何の処理・メモリが減るか説明できない変更は行わない。無駄がなければ完了とする。
- 改善の前提として利用者に電池持ちの比較測定を要求しない。未測定の効果を成果として報告しない。

文字盤1.9.1は利用者が実機で数日間使用し、正常動作を確認済み。
これを基準に、変更で影響する表示・機能を確認する。

1.9.2ではデジタル表示を時・分のみに変更。アナログ秒針は維持する。

## 手順

ZIPを展開し、watchface ディレクトリで実行します。

```sh
npm ci
node build.js build
```

成果物は dist ディレクトリの .zab ファイルです。
.zab はZIP形式で、その中の .zpk が端末向けパッケージです。

ビルド時にZeppの機種情報を取得します。取得に失敗した場合は、
ネットワークを確認してビルドを再実行してください。
